Connect pool history

The indexer code is ready. Create its home in Graph Studio and add the deploy key locally. We can then deploy it and connect the live data.

1. Sign in to Graph Studio

Open Graph Studio ↗. Connect a supported wallet, such as MetaMask, Coinbase Wallet or WalletConnect. This wallet manages your Graph project; it can be different from your LP Copilot wallet.

2. Create the project

Click Create a Subgraph. Use the name below and check the generated slug on its details page.

NameLP Copilot Base Sepolia
Expected sluglp-copilot-base-sepolia

If the slug differs, share the slug so the deployment command can be updated. You do not need to run the initialization commands shown by Studio; the project already contains the schema, ABI and mapping.

3. Save the deploy key

Find Deploy Key on the subgraph details page. This is different from the query key under API Keys. Copy it into the existing local file /Users/bx/dev/LP-copilot/.env, preserving its other settings:

GRAPH_STUDIO_DEPLOY_KEY=your_deploy_key_here

Keep the key in that file rather than chat. Tell us when it is saved. That is enough to continue with deployment.

4. Deployment and connection

We will compile and deploy the existing indexer, save its development query URL as BASE_SEPOLIA_GRAPH_URL, and check that indexing catches up. Studio deployment is the testing step; publishing to The Graph Network is a separate onchain action and is not required for this local test.
